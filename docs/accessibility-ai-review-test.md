# 无障碍与自由绘制 AI 复核测试版（基于 18.3）

历史测试说明。正式发布请使用 18.3.1 的安装包及匹配 AI 组件；商店和 WinGet 审核进度独立。

## 启动与组件
1. 解压便携包。先从托盘退出正在运行的其他 GestureSign 版本，再运行 GestureSign.WinUI.exe，避免旧后台处理手势。
2. “选项 → 无障碍：显示与操作”提供大控件、预览轨迹编号和触控板边缘宽度（3–20%）。
3. AI 主程序仍不内置。请使用同目录交付的 GestureSign-IntentDlc-18.3.1-win-x64.zip。可在线下载或通过“导入组件包”安装对应架构的组件。
4. 如果已经安装旧组件，先点“卸载组件”，再导入配套 ZIP。卸载组件不删除个人训练样本和模型；两个程序版本共用用户数据目录。
5. 开启 AI评分或 AI 否决后，两指、三/四指以及自定义绘制（含单指）始终参与判断，覆盖绑定的所有动作。旧范围开关和排除名单不再跳过复核。AI评分只记录、不拦截；AI 否决在执行前判断。

便携版仍依赖 .NET 10 Desktop Runtime 和 Windows App Runtime 2.x（至少 2.3.1.0）。缺少运行库时先安装系统提示的匹配 x64 运行库；不是 AI 组件缺失。

## 行为
- 仅触控板自由绘制完成后、执行动作前复核，TipTap、边缘和快捷键不进入这个流程。
- 对候选模板检查持续转向，配合已有连续滚动场景判断和本地意图评分。小折角不会单凭局部转向就作为完整 L 的证据。
- 旧双指模型仅声明覆盖双指；其他指数量须各自补充正常操作/有意手势样本并重新训练。未覆盖、推理超时或失败时，普通动作沿用原识别，智能关闭暂不执行。
- 当前同步推理截止时间为 45 毫秒，系统调度可能使实际等待更长；日志包含耗时、指数量、后端和错误，尚无实机延迟、误判率或续航提升保证。
- 电池供电暂停自动训练，不因此关闭 AI 否决；手动训练仍可使用。推理线程关闭空闲忙等。
- AI 否决保留合并通知和纠错记录，开启通知即附带提示音；颜色之外有状态文字和轨迹编号。

## 验证范围
已完成编译、主程序/组件拆包校验、模型及后台协议回归，测试界面可以启动且显示新增选项。
键盘焦点、屏幕阅读器实际朗读、高对比度/大字体全部页面仍需人工体验；目前是基础无障碍改进，不是完整无障碍审计。
本包不包含个人训练数据，不会自动上传样本。
